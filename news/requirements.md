# Pulse · 热榜阅读 App 需求说明

## 1. 项目概述

Pulse 是一款 iOS 端热榜聚合阅读应用，使用 Flutter 开发。用户导入 JSON 数据源配置后，可在同一 App 内切换查看微信、知乎、微博、百度等 81 个来源的热榜内容，并进行收藏与阅读。

## 2. 目标用户

- 需要跨平台快速浏览中文热榜的资讯重度用户
- 希望减少在各 App 之间切换成本的读者

## 3. 功能需求

### FR-1 数据导入

| 编号 | 需求 |
| --- | --- |
| FR-1.1 | 支持导入 `kind: "sources"` 的源配置 JSON，批量写入来源列表 |
| FR-1.2 | 支持导入 `kind: "feed"` 的新闻快照 JSON，写入本地文章库 |
| FR-1.3 | 导入前校验 `version` 与必需字段，失败时精确到字段路径 |
| FR-1.4 | 支持从「文件」App 选择，或拖拽导入，单文件上限 20 MB |
| FR-1.5 | 导入完成后展示结果摘要，允许跳过坏条目继续导入 |

### FR-2 热榜信息流

| 编号 | 需求 |
| --- | --- |
| FR-2.1 | 顶部以来源为单位切换，默认展示常用来源与「全部 81」入口 |
| FR-2.2 | 点击来源即加载该来源 Top 50，切换来源不跳转页面 |
| FR-2.3 | 列表展示排名、标题、热度值、更新时间 |
| FR-2.4 | 排名前三使用强调色区分 |
| FR-2.5 | 支持下拉刷新与手动刷新按钮 |

### FR-3 来源管理

| 编号 | 需求 |
| --- | --- |
| FR-3.1 | 展示全部来源，按分类分组 |
| FR-3.2 | 支持按名称搜索来源 |
| FR-3.3 | 支持分段筛选：全部 / 已启用 / 最近使用 |
| FR-3.4 | 支持启用与停用单个来源 |

### FR-4 文章阅读

| 编号 | 需求 |
| --- | --- |
| FR-4.1 | 展示标题、来源、排名、热度与正文 |
| FR-4.2 | 底部常驻收藏、分享、打开原文三个操作 |
| FR-4.3 | 打开原文时使用系统浏览器 |

### FR-5 收藏

| 编号 | 需求 |
| --- | --- |
| FR-5.1 | 收藏入口位于「设置 → 我的收藏」 |
| FR-5.2 | 展示收藏总数、已读总数与收藏来源数 |
| FR-5.3 | 收藏列表支持按时间排序 |
| FR-5.4 | 详情页收藏状态与收藏列表实时同步 |

### FR-6 自动刷新

| 编号 | 需求 |
| --- | --- |
| FR-6.1 | 设置页提供自动刷新开关，固定间隔 30 分钟 |
| FR-6.2 | 仅刷新已启用来源 |
| FR-6.3 | App 进入后台时暂停，回到前台立即补一次刷新 |
| FR-6.4 | 展示上次刷新时间与成功来源数量 |

### FR-7 设置

| 编号 | 需求 |
| --- | --- |
| FR-7.1 | 设置页分组：刷新、内容、外观、关于 |
| FR-7.2 | 内容组包含：我的收藏、数据源、导入 JSON、导出数据 |
| FR-7.3 | 外观组包含主题与字号 |
| FR-7.4 | 关于组展示版本号与检查更新 |

## 4. 非功能需求

| 编号 | 需求 |
| --- | --- |
| NFR-1 | 深色主题为默认外观 |
| NFR-2 | 离线优先：热榜结果落本地缓存，无网络时展示上次快照并标注时间 |
| NFR-3 | 列表滚动稳定，单行标题最多两行，避免高度抖动 |
| NFR-4 | 兼容 iPhone 15 Pro（390 × 844 pt）及以上尺寸 |
| NFR-5 | 冷启动到首页可交互不超过 1.5 秒 |

## 5. 数据契约

### 5.1 源配置

```json
{
  "version": 1,
  "kind": "sources",
  "sources": [
    {
      "id": "WnBe01o371",
      "name": "微信",
      "type": "24h热文榜",
      "category": "综合",
      "url": "https://base.itab.link/api/top/list?lang=cn&id=WnBe01o371&size=50"
    }
  ]
}
```

### 5.2 新闻快照

```json
{
  "version": 1,
  "kind": "feed",
  "sourceId": "WnBe01o371",
  "sourceName": "微信",
  "items": [
    {
      "rank": 1,
      "title": "标题",
      "hotValue": "10.0万",
      "link": "https://...",
      "read": false,
      "saved": false
    }
  ]
}
```

## 6. 数据来源

- 分类接口：`https://base.itab.link/api/top/category`
- 单榜接口：`https://base.itab.link/api/top/list?lang=cn&id={id}&size=50`
- 返回字段：`index` / `title` / `hotValue` / `link`

## 8. 验收标准

1. 导入 `hot-sources.json` 后，来源列表出现 81 个来源、20 个分类。
2. 导入 `sample-news.json` 后，微信来源下出现 30 条文章。
3. 切换来源后 1 秒内展示对应列表。
4. 开启自动刷新后，30 分钟内列表时间戳自动更新。
5. 收藏后返回设置页，收藏计数同步加 1。
